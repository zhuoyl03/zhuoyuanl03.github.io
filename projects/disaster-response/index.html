CLIP adaptation for disaster-response classification

Purdue VIP AI4SMA · Spring 2026
Team: Yubeen Oh, Zhuoyuan Li, Akhilesh Tuttagunta, and Logan Fossum

Start with the labels

CrisisMMD pairs disaster-related social-media text and images, but the text-specific and image-specific labels do not always agree. Training against a single target can obscure that disagreement. I examined the annotation inconsistencies, retained samples with matching modality labels, and consolidated the eight humanitarian categories into five.

My contribution was the label analysis, agreement-based filtering, label consolidation, and comparison of CLIP adaptation strategies. The team's report also covers other classification pipelines; those are separate from my adaptation study.

How much adaptation helps?

Using CLIP ViT-B/32, I compared a frozen backbone with a trained classifier head, LoRA adapters with a trained head, and full fine-tuning. Each method was evaluated on the agreed-only data splits using accuracy, weighted F1, and macro-F1.

Task 2: agreed-only, consolidated five-class test set
AdaptationAccuracyMacro-F1
Head-only89.3%83.9%
LoRA88.8%70.9%
Full fine-tuning88.7%79.7%

Head-only training gave the strongest result in this comparison. The accuracy differences were small, but macro-F1 exposed larger differences across the humanitarian categories. For the binary informativeness task, head-only training achieved 93.2% accuracy and 92.2% macro-F1.

Interpreting the comparison

Agreement filtering changes which examples are evaluated, and label consolidation changes the task itself. These numbers should not be compared directly with results on the unfiltered eight-class CrisisMMD benchmark. They describe the reported runs, not a statistical claim that freezing CLIP is always better than fine-tuning.

The useful lesson from these experiments is to examine the data and per-class behavior before assuming that updating more of the model will help.
